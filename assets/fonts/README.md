# Local web fonts

Same families previously loaded with next/font/google. Self-hosted so dev and production builds do not fetch Google Fonts.
Files downloaded from https://github.com/google/fonts/tree/main/ofl on 19 October 2026.

- anuphan.ttf: ofl/anuphan/Anuphan[wght].ttf — Anuphan-OFL.txt
- archivo.ttf: ofl/archivo/Archivo[wdth,wght].ttf — Archivo-OFL.txt
- courier-regular.ttf and courier-bold.ttf: ofl/courierprime — CourierPrime-OFL.txt

Original font files are unmodified. Keep the supplied SIL Open Font License notices when redistributing.
