# ล้างแผนที่และเริ่มสร้างใหม่

หน้า [ควบคุมหุ่น](http://localhost:3000/control) → **โหมดการใช้งานหุ่น** → **เริ่มสร้างแผนที่ใหม่ / Clear map**

1. เข้าระบบด้วยบัญชี Admin หุ่นต้องออนไลน์ ว่าง ไม่มีงานหรือ manual lock และไม่ได้อยู่ใน E-Stop การเปิดหน้านี้ไม่ปลด E-Stop ให้เอง
2. พิมพ์ `CLEAR MAP` ให้ตรง แล้วกด **ล้างแผนที่และเริ่มสร้างใหม่**
3. ระบบดาวน์โหลด STCM จากหุ่น บันทึกลง PostgreSQL และอ่านกลับตรวจขนาด/SHA-256 ก่อนเปลี่ยนข้อมูลบนหุ่น หากสำรองไม่ได้จะไม่ล้าง
4. ระบบพัก mapping ล้างกริด SLAM และตรวจว่ากริดเดิมหาย/เป็นข้อมูลไม่รู้จัก ลบ POI และกำแพงเสมือนเก่าที่ยังเหลือ ปิดนโยบายกลับจุดประจำ แล้วเปิด mapping สำหรับสร้างแผนที่ใหม่ ไม่มีคำสั่งเดินถูกส่งในขั้นตอนนี้
5. ใช้การควบคุมด้วยมือสำรวจพื้นที่ เมื่อเสร็จให้ปล่อย lock บันทึกแผนที่ใหม่ลงคลัง STCM และเลือกโหมดปกติ
6. ไปหน้าแผนที่ → ระบุตำแหน่งหุ่น ยืนยันตำแหน่ง/ทิศจริง และรอคุณภาพอย่างน้อย 50 ก่อนนำทาง เพิ่ม POI และจุดประจำสำหรับแผนที่ใหม่ตามต้องการ
7. ตั้งตำแหน่งแท่นชาร์จของแผนที่ใหม่บนหุ่นด้วยเครื่องมือของหุ่น ตรวจพิกัดที่หน้าควบคุม แล้วกด **ยืนยันตำแหน่งแท่นชาร์จใหม่** ระบบจะกันกลับแท่นไว้จนกว่าจะยืนยัน ไม่ใช้พิกัดแท่นเก่าโดยอัตโนมัติ

หากปุ่มเป็นสีเทา ให้ดูสถานะหุ่น สิทธิ์ Admin งาน/lock และ E-Stop บนหน้าควบคุม ห้ามปลด E-Stop จนกว่าพื้นที่และหุ่นพร้อม

## กู้คืน

ไฟล์เดิมจะอยู่ที่ **คลังแผนที่ → ไฟล์ STCM** ชื่อขึ้นต้น “สำรองก่อนล้างแผนที่” รายการในคลังและไฟล์สำรองเดิมไม่ถูกลบ

เลือกไฟล์แล้วกด **โหลดบนหุ่น** ระบบสำรองแผนที่ปัจจุบัน ปิดโหมดสร้างแผนที่ให้ และรีเฟรชแผนที่สดหลังโหลดสำเร็จ อัปโหลดไฟล์ลงคลังแล้วต้องกดโหลดบนหุ่นอีกครั้ง จากนั้นไป **แผนที่ → ระบุตำแหน่งหุ่น** เลือกตำแหน่งและทิศจริงก่อนนำทาง

ทดสอบกู้สำรองก่อนล้างบนหุ่นจริงวันที่ 21 ตุลาคม 2569 สำเร็จ แผนที่ 434×360, POI 5 จุด และกำแพง 18 เส้นกลับมาครบ ตรวจแสดงผลใน Chrome แล้ว ไม่ส่งคำสั่งเดินในรอบกู้ หลักฐาน [ผลกู้](../reports/map-restore-2026-10-21/restore.json), [ผลเว็บ](../reports/map-restore-2026-10-21/browser.json)

หากล้างได้บางส่วน ระบบจะแจ้งรหัสไฟล์สำรองและพยายามปิด mapping คงการบล็อกนำทางไว้ เลือกโหลดไฟล์สำรองนั้นกลับจากคลัง แล้วระบุตำแหน่งหุ่นก่อนนำทางอีกครั้ง สามารถโหลดสำรองก่อนล้างกลับได้แม้แผนที่ปัจจุบันว่างจนส่งออก STCM ไม่ได้

## ขอบเขตและผลตรวจ

- ผู้ใช้ยืนยันว่าโหมดสำรวจทำงานผ่านแล้ว
- การเพิ่มฟังก์ชัน Clear map รอบนี้ตรวจ Backend 77 tests, typecheck และ build ผ่าน ตรวจ UI บนเว็บจริงแล้ว โดยไม่เรียก endpoint ล้างแผนที่ ในขณะตรวจ UI ปุ่มถูกปิดตามสถานะหุ่น
- ทดสอบคำยืนยัน สิทธิ์ Admin หุ่นไม่ว่าง สำรองล้มเหลว firmware ปฏิเสธ กริดเดิมไม่ถูกล้าง การกู้เมื่อแผนที่ว่าง การลบ artifacts และการกันนำทาง/แท่นข้ามการเปิดโปรแกรมใหม่กับข้อมูลทดสอบแยก
- **ยังไม่ได้ล้างแผนที่บนหุ่นจริงในรอบพัฒนานี้** การลบจริงจะเกิดเมื่อ Admin ยืนยันและกดปุ่มเท่านั้น
- หาก firmware ปฏิเสธการลบ POI/กำแพง การล้างจะรายงานว่าไม่สำเร็จพร้อมไฟล์กู้คืน ไม่อ้างว่าสำเร็จหรือเริ่ม mapping ต่อทั้งที่ artifacts เก่ายังอยู่

อ้างอิง API ทางการ: `DELETE /api/core/slam/v1/maps` สำหรับล้างกริด และ API POI/lines สำหรับ artifacts ใน [SLAMTEC OpenAPI](https://docs.slamtec.com/opt/swagger-conf.json)
