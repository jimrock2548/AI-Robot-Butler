# ลบไฟล์แผนที่ที่บันทึกไว้

1. เข้าระบบด้วย Admin แล้วเปิด **คลังแผนที่ / จุดประจำ** (`http://localhost:3000/map-library`)
2. ในส่วน **แผนที่ SLAM บนหุ่น · ไฟล์ STCM** กด **ลบแผนที่** ที่รายการที่ต้องการ
3. ตรวจชื่อไฟล์ในหน้าต่างยืนยันแล้วตกลง ไฟล์และข้อมูลรายการจะถูกลบจากฐานข้อมูลถาวร ดาวน์โหลดสำเนาก่อนลบได้

ลบได้แม้หุ่นออฟไลน์ ไม่มีการส่งคำสั่งล้างแผนที่/POI/กำแพงหรือสั่งเดินบนหุ่น เฉพาะ Admin ลบได้ ระบบกันลบไฟล์ที่โหลดใช้อยู่และสำรองก่อนล้างที่ยังจำเป็นต่อการกู้คืน โดยตรวจซ้ำที่ Backend และกันชนกับการโหลด/ล้างแผนที่

หากปุ่มเป็นสีเทา ดูป้าย **โหลดใช้อยู่** หรือ **สำรองสำหรับกู้คืน** ไฟล์ใช้งานต้องโหลดแผนที่อื่นก่อน ส่วนสำรองต้องตั้งแผนที่ ตำแหน่ง และยืนยันแท่นชาร์จใหม่ให้เสร็จก่อนลบ ข้อมูลป้องกันอ่านจากฐานข้อมูลได้โดยไม่ต้องรอ API หุ่น

ขอบเขตฟังก์ชันนี้คือคลังไฟล์ STCM ไม่รวมแผนผัง JSON ด้านล่าง

API: `DELETE /api/robot/map-archives/:id` (Admin, 204) และ `GET /api/robot/map-archives/protection` สำหรับป้าย/ปุ่ม รายการและ blob ลบด้วยคำสั่งฐานข้อมูลเดียว มี audit `robot.map.archive.delete` เก็บชื่อ รหัส และ SHA256
