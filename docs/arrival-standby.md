# ถึงจุดหมายและกลับจุดประจำ

เมื่อหุ่นรายงานว่างานไป POI สำเร็จจริง Robot Interface จะอ่าน **“ถึงจุดหมายแล้วครับ”** หนึ่งครั้งสำหรับงานนั้น หากเปิดอ่านคำตอบไว้และระบบเสียงของอุปกรณ์พร้อม บน iPad ต้องแตะ **เปิดเสียงตอบกลับ** หนึ่งครั้งก่อนใช้งาน

หน้าเว็บแสดงหน้าถึงจุดหมาย 5 วินาทีแล้วกลับหน้าคุย AI อัตโนมัติ โดยเก็บบทสนทนาเดิมไว้ ยังมีปุ่มกลับทันทีและปุ่มหยุด การเปลี่ยนหน้านี้ไม่ส่งหรือยกเลิกคำสั่งหุ่น

เมื่อเปิด **กลับจุดประจำอัตโนมัติหลังนำทางถึงจุดหมาย** ใน Admin และมี POI จุดประจำที่ถูกต้อง Backend รออย่างน้อย **5 วินาที นับจากยืนยันถึงจุดหมาย** แล้วตรวจการเชื่อมต่อ สถานะว่าง แผนที่ จุดประจำ และคุณภาพนำทางก่อนส่งงานกลับ ไม่ใช่การจับเวลาหลังเสียงจบ เพราะเสียงอ่านทำงานบน iPad/เบราว์เซอร์แยกจากตัวหุ่น

ระหว่างรอมีปุ่ม **หยุด / ยกเลิกกลับจุดประจำ** บนหน้าถึงปลายทาง กดแล้วกลับหน้าคุย AI และยกเลิกการกลับที่รออยู่ หากงานกลับเริ่มแล้วปุ่มนี้หยุดงานอัตโนมัติไป STANDBY ได้ด้วย การหยุดงานของเจ้าหน้าที่และ auto-dock ยังใช้สิทธิ์เดิม

การหยุดด้วยเสียง ปุ่มหยุด E-Stop ควบคุมด้วยมือ งานใหม่ เปลี่ยนโหมด/แผนที่/จุดประจำ หรือการขาดการเชื่อมต่อที่ตรวจพบระหว่างรอ จะไม่ทำให้การกลับเดิมกลับมาเริ่มภายหลัง ไม่มีการสั่งกลับย้อนหลังหลังเปิด Backend ใหม่ งานกลับจุดประจำเองและงานกลับแท่นไม่สร้างวงจรกลับซ้ำ

รอบพัฒนา 29 ต.ค. 2569 ไม่สั่งหุ่นจริงเดิน อ่านค่าแล้วพบว่ามีจุดประจำและนโยบาย `after_job` อยู่ก่อนแล้ว จึงไม่เปลี่ยนการตั้งค่านั้น ตรวจ Backend 83/83, typecheck/build ทั้งระบบ และ browser fixture ผ่าน รวมเวลา 0/4999/5000 ms, ไม่วนกลับ, หยุด/ลิงก์ขาด/manual, หยุดระหว่างอ่านแผนที่ก่อน dispatch และหยุดงาน STANDBY ที่เริ่มแล้ว เสียงจริงบน iPad ยังต้องให้ผู้ใช้ยืนยัน
