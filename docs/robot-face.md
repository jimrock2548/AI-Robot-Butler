# หน้าจอใบหน้าเฮอร์มีส

เปิด Robot Interface ที่ `http://localhost:3001/ai` เพื่อดูหน้าจอใบหน้าตามภาพตัวอย่างใน `img/หน้าจอหุ่นฃ/ตัวอย่างหน้าจอหุ่นยนต์.png`

- แตะใบหน้าหรือ **พิมพ์ข้อความ / จุดหมาย** เพื่อเปิดแผงแชต ปิดแผงแล้วบทสนทนายังคงอยู่
- กด **พูดกับเฮอร์มีส** เพื่อรับเสียง จากนั้นตรวจข้อความในแผงแชตและกดส่ง
- เปิด **เลือกจุดหมาย** เพื่อใส่คำขอนำทางลงช่องพิมพ์ ตรวจแล้วกดส่ง
- การเรียกชื่อและการตั้งค่าเสียงยังอยู่ในแผงแชต
- ปุ่ม **หยุด / ยกเลิกงาน** อยู่ด้านล่างทั้งในหน้าใบหน้าและขณะเปิดแชต
- สีหน้าเปลี่ยนตามสถานะจริงของหน้าเว็บ: รอ ฟัง คิด พูด เจ้าหน้าที่รับช่วง และข้อผิดพลาด ไม่ใช่การตรวจจับอารมณ์
- ระบบจะไม่เริ่มฟังไมค์หรือส่งคำสั่งนำทางเพียงเพราะเปิดหน้าใบหน้า

ไฟล์หลัก: `apps/kiosk/src/app/kiosk/RobotFace.tsx`, `ChatFlow.tsx` และ `apps/kiosk/src/app/globals.css` ใช้ SVG/CSS จึงคมชัดตามขนาดจอ ไม่ใช้รูปถ่ายหุ่นเป็นภาพพื้นหลัง

ตรวจ UI ด้วย `node scripts/check-robot-face-ui.mjs` ขณะเปิดเว็บที่พอร์ต 3001 และ Chrome CDP ที่ 9229 สคริปต์แทนทุก kiosk API ด้วย fixture ในแท็บทดสอบและใช้ speech stub จึงไม่มีการทดสอบเสียงหรือเคลื่อนที่หุ่นจริง ผลและภาพอยู่ใน `reports/robot-face-2026-10-23/`
