## 3. Website: Admin เห็นแชตและรับช่วงได้

Admin และ Operator เห็น user/assistant/staff ผ่าน SSE เจ้าหน้าที่รับช่วงได้คนเดียวในแต่ละ session การรับช่วง abort คำตอบ AI ที่ค้างและคำสั่งที่ยังไม่ dispatch แต่ไม่ยกเลิกการเดินที่เริ่มไปแล้ว ต้องใช้ปุ่มหยุดงาน ข้อความเจ้าหน้าที่ปรากฏที่ Robot Interface ในรอบ polling ประมาณหนึ่งวินาที และอ่านด้วย TTS ได้

## 5. AI: รับเสียง เรียกชื่อ และพูดตอบ

กดพูดหรือฟังคำเรียก ผ่าน browser STT ตรวจคำเรียกจาก transcript ไม่ใช่ wake model offline เมื่อได้ยินคำเรียกอย่างเดียวให้เวลาคำสั่งถัดไป 8 วินาที ข้อความถูกแสดงก่อนและต้องกดส่ง TTS ปิดการฟังก่อนพูดและไม่เปิดไมค์ต่อเอง เสียงทดสอบใน browser integration เป็น stub ยังไม่ได้วัดไมค์จริง ภาษาไทยอาจต้องติดตั้งชุดเสียง และ browser STT บางรุ่นใช้อินเทอร์เน็ต

หลักฐาน: browserVoice.ts; packages/shared/src/voice.ts

## 6. Method: Rules อ่านรูปประโยคอย่างไร

ตัวอย่างย่อจากโค้ดจริง normalize ใช้ Unicode NFC แปลงตัวเล็กและยุบช่องว่าง จากนั้น regex negative จับคำปฏิเสธก่อนกฎคำขอ ไม่ได้ใช้ระบบตัดคำภาษาไทยเป็น token เครื่องหมาย | คือทางเลือก ^ คือขึ้นต้น และวงเล็บจัดกลุ่ม ขั้นตอนนี้จึงไม่ส่ง “อย่าพาไปห้องประชุม” เป็นคำสั่งเดิน ข้อความในสไลด์เป็น excerpts ไม่ใช่ฟังก์ชันเต็ม

หลักฐาน: services/robotLanguage.ts

## 7. Method: ชื่อจุดหมายและขอบเขตคำสั่ง

กฎคำขอใช้ regex ที่ขึ้นต้นและมีคำสุภาพเป็น optional เช่น ช่วยพาไปห้องประชุม ระบบจับชื่อและ alias จาก catalog จริง ใช้ชื่อที่เฉพาะเจาะจงกว่าชื่อย่อย ถ้าชื่อซ้ำหรือกำกวมให้เลือกใหม่ จำกัดคำขอธุรกรรม เช่น เรียกแท็กซี่ โดยตอบนอกขอบเขตก่อนเรียกโมเดล และไม่สร้างงาน ตัวอย่าง regex บนสไลด์เป็น excerpt จากนิยาม request ที่ยาวกว่า

หลักฐาน: services/robotLanguage.ts; services/navigationScope.ts
