# รายงานผลพัฒนางานที่ไม่ต้องเชื่อมต่อหุ่น — 19 ตุลาคม 2569

รอบนี้พัฒนาบน PC และทดสอบกับ Mock โดยไม่ติดต่อ IP หุ่น ไม่สั่งเดิน ไม่เปลี่ยน SLAM และไม่สร้าง POI บนอุปกรณ์จริง
แยกชุดทดลอง Backend 4010, Admin 3010, Robot Interface 3011 จากบริการเดิม

## ผลตามคอมเมนต์อาจารย์ 13 ข้อ

| ข้อ | ผลงานรอบนี้ | ขอบเขตที่ยังต้องตรวจหรือทำกับอุปกรณ์ |
|---|---|---|
| 1. Field Test / คลิปกับพี่ปลั๊ก | จัดทำ field-test-plan ครอบคลุม 13 กรณี เกณฑ์ผ่านและลำดับถ่ายคลิป | ยังไม่ได้นัด ทดสอบหน้างาน หรือถ่ายคลิปจริง |
| 2. หลายแผนที่ | เพิ่มคลังแผนที่หลายสถานที่ ID แยกกัน นำเข้า/ส่งออก JSON แก้ไข เลือกแสดง และ POI แยกตามสถานที่ | ยังไม่อัปโหลด .stcm หรือสลับ active SLAM บนหุ่น |
| 3. หน้า AI คล้ายหน้าจอบริการ | ปรับ Robot Interface เป็นปุ่มสัมผัสขนาดใหญ่ ตัวละคร ปุ่มจุดหมาย แชต และเครื่องมือเสียง รองรับจอเล็ก | เป็นร่างแนวหน้าจอบริการ ยังรอภาพอ้างอิงตี๋น้อยเพื่อปรับรายละเอียดให้ตรง |
| 4. Wake word | ตั้งคำเรียกได้ ตรวจคำเรียกจาก STT ใช้กับคำสั่งในประโยคเดียวหรือประโยคถัดไปภายใน 8 วินาที รับหนึ่งคำสั่งต่อการเรียก | ยังไม่ใช่โมเดลตรวจ wake word แบบ offline และยังไม่ได้วัด false activation จากเสียงจริง |
| 5. Admin ดูแชตสด | แสดงข้อความผู้ใช้ AI และเจ้าหน้าที่ แยก session อัปเดตสดผ่าน SSE มีประวัติย้อนหลัง | ตรวจในเครื่องแล้ว; ยังไม่วัดเครือข่ายหน้างานหลายอุปกรณ์ |
| 6. จุดประจำ | ตั้ง standbyCode แยกแต่ละแผนที่ เลือกนโยบาย manual/after_job และ preview ตำแหน่งได้ | after_job ยังเป็นค่าที่เตรียมไว้ ไม่ได้ส่งคำสั่งกลับจริงอัตโนมัติ |
| 7. Admin โต้ตอบผ่านหุ่น | รับช่วง ตอบข้อความ ส่งถึง Robot Interface คืนให้ AI และอ่านข้อความเจ้าหน้าที่ด้วย TTS ได้ | ไม่ใช่โทรศัพท์เสียงสดสองทาง ยังรอไมค์/ลำโพงบนหุ่น |
| 8. LLM พูดได้ | เพิ่มปุ่มอ่านแต่ละข้อความ อ่านคำตอบอัตโนมัติ และหยุดเสียง ปิดการฟังก่อนพูด | ใช้เสียงเบราว์เซอร์/ระบบ ต้องตรวจเสียงไทยและยังไม่ได้ย้าย local TTS ไป Jetson |
| 9. ยุบสไลด์ | จัดทำชุดใหม่ 9 หน้า PPTX/PDF แยก Website และ AI ใช้ภาพหน้าจอจริงจากชุดจำลอง | ผล Field Test ต้องเติมภายหลัง |
| 10. ตัวอย่าง syntax / Method | แสดงโค้ด normalize, regex คำปฏิเสธและ branch คำขอ อธิบาย ^, กลุ่ม, ?, ทางเลือก และช่องว่าง พร้อมตัวอย่างก่อน/หลัง | โค้ดบางช่วงเป็น excerpts ที่ระบุไว้ ไม่ใช่ฟังก์ชันเต็ม |
| 11. ขอบเขตนำทาง | เปิด AI_NAVIGATION_ONLY=true เป็นค่าปริยาย คำกำกวมขอให้เลือก/บอกชื่อใหม่ ไม่ resolve “ที่นั่น” จากบทสนทนาเก่า | ยังต้องเก็บถ้อยคำผู้ใช้จริงเพื่อปรับกฎ |
| 12. คำขอทำไม่ได้ | ปฏิเสธเรียกแท็กซี่ จอง ซื้อ ชำระเงิน พร้อมบอกขอบเขตและทางเลือก ไม่สร้างงานหุ่น | ไม่ได้เชื่อมบริการเรียกรถหรือธุรกรรมภายนอก |
| 13. รับคำสั่งเสียง | กดพูด → STT → ข้อความให้ตรวจ → กดส่งเข้าระบบเดิม รองรับการพิมพ์เมื่อเสียงไม่พร้อม | ยังไม่มีผลความแม่นยำจากไมค์จริงหรือ benchmark บน Jetson |

## ผลการตรวจ

- Backend automated tests ผ่าน 58/58 รวมระบบเดิมและกรณีใหม่
- TypeScript ผ่าน Admin, Backend และ Robot Interface
- Production build ผ่าน Admin, Backend และ Robot Interface หลังเปลี่ยนฟอนต์เดิมเป็นไฟล์ local พร้อมใบอนุญาต
- Chrome headless integration ผ่าน 5 กลุ่มงาน: wake gate/preview, คำขอทำไม่ได้, Admin live/handover/staff reply/TTS stub, จอเล็ก และคลังสองแผนที่/จุดประจำ ไม่มี JavaScript runtime error
- SpeechRecognition และ SpeechSynthesis ใน browser test เป็นตัวจำลอง ไม่ใช่ผลฟังเสียงจริง
- PostgreSQL apply migration ใหม่แล้ว ตรวจเก็บแชต แผนที่และจุดประจำหลัง disconnect ด้วย Prisma อีก connection ได้ รวมการเขียน document ต่อเนื่องโดยไม่ทับ revision ล่าสุด
- ข้อมูลตรวจ storage ใช้ UUID เฉพาะแล้วล้างเฉพาะสอง document ที่สร้าง ไม่ลบข้อมูลผู้ใช้เดิม
- คะแนน benchmark AI 40 กรณีจากรอบก่อนยังเป็นผลเก่า ไม่ได้รัน LLM benchmark ใหม่ในรอบนี้

## การเก็บข้อมูลและสิทธิ์

เพิ่มตาราง service_documents เก็บ conversation และ map-library เป็น JSON พร้อมชนิดและเวลาอัปเดต
ข้อความ user ถูกบันทึกก่อนเริ่มตอบ คำตอบถูกบันทึกเมื่อจบหรือยกเลิก; หากโปรเซสตายกลางทาง ข้อความส่วนที่ยังไม่บันทึกอาจหาย
แต่ละ session มี capability token แยกกัน ฝั่งเซิร์ฟเวอร์เก็บ hash; Admin/Operator อ่านแชตได้ Viewer ไม่ได้
รับช่วงได้ครั้งละเจ้าหน้าที่หนึ่งคน การรับช่วง abort inference ที่ค้าง แต่ไม่ยกเลิก navigation ที่ dispatch ไปแล้ว
ยังไม่มีนโยบายลบแชตอัตโนมัติ ต้องกำหนดก่อนใช้งานจริง
ชุด Mock ใช้ memory ข้อมูลหายเมื่อปิด Backend; PostgreSQL เก็บถาวรตาม migration

## งานต่อไปที่ต้องใช้หุ่นจริง

ยืนยันแก้ POI และลิงก์ขาด → ตรวจนำทาง/ยกเลิก/หยุด/กลับแท่น → เชื่อมสลับแผนที่จริง → เชื่อมเดินกลับจุดประจำ → วัดเสียงจากไมค์/ลำโพงจริง → ทดสอบและวัดทรัพยากรบน Jetson → เก็บคลิปกับพี่ปลั๊ก

ต้นแบบ STT อาจส่งเสียงไปผู้ให้บริการของเบราว์เซอร์และต้องใช้อินเทอร์เน็ต จึงไม่อ้างว่าเสียงเป็น local/offline ทั้งหมด:
[SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition), [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)
