# รูปเล่มโครงงานฉบับร่าง

จัดทำ 12 ตุลาคม 2569 จากโค้ดและหลักฐานในโปรเจ็กต์ โดยตรวจตัวอย่าง 10 ไฟล์ในโฟลเดอร์ตัวอย่างรูปเล่ม และใช้โครงสร้าง 6 บทตามเล่มไทยส่วนใหญ่

- **AI-Robot-Butler-Report.docx**: ไฟล์ Word ที่แก้ไขได้ มีสารบัญ สารบัญภาพ และสารบัญตารางเป็น field ที่อัปเดตได้
- **AI-Robot-Butler-Report.pdf**: ไฟล์ PDF สำหรับอ่าน ตรวจแล้ว 38 หน้า มีสารบัญระบุเลขหน้าของ PDF จริง
- **AI-Robot-Butler-Report-source.md**: เนื้อหาต้นฉบับสำหรับแก้/ติดตามการเปลี่ยนแปลง
- **report-manifest.json**: วันที่ ขอบเขต และ SHA-256 ของหลักฐานต้นทาง
- **validation.json**: ผลตรวจจำนวนหน้า ตาราง ภาพ และ benchmark 40 กรณี
- **template-review.json**: บันทึกการตรวจไฟล์ตัวอย่าง

ใช้ Word รูปแบบ .docx ซึ่งแก้ไขได้ ไม่ใช่ไฟล์ .doc รุ่นเก่า ตัวส่งออก .doc/PDF ของ Microsoft Word ค้างในเครื่องนี้ จึงจัดทำ PDF จากเนื้อหาเดียวกันด้วย Chrome headless; การตัดหน้า Word และ PDF อาจต่างกัน เลขหน้าในสารบัญแต่ละไฟล์อ้างการจัดหน้าของไฟล์นั้น เมื่อแก้ Word ให้เลือกสารบัญแล้วอัปเดตทั้งสารบัญก่อนส่งออกใหม่

ยังต้องเติมชื่อโครงงานที่อนุมัติ ผู้จัดทำ รหัสนักศึกษา อาจารย์ สถาบัน ปีการศึกษา กิตติกรรมประกาศ และข้อมูลหน้าอนุมัติ ไม่ได้คัดลอกชื่อบุคคลจากเล่มตัวอย่าง รายงานแยกผล software/dry-run ออกจากผลตรวจรับการเดินจริง และไม่ได้ต่อหุ่นหรือเปิดโมเดลระหว่างจัดทำ

ผล benchmark ในเล่มเป็นหลักฐานวันที่ 7 ตุลาคม 2569 ไม่ใช่ผลทดลองใหม่หรือ benchmark บน Jetson ภาพประกอบเป็นแผนภาพที่เขียนจากโค้ด ไม่ใช่ภาพหน้าจอการทำงานจริง

## การสร้างซ้ำ

สคริปต์ Python ใช้ python-docx, PyMuPDF และ Pillow เครื่องนี้มี Python จาก QGIS; packages เพิ่มอยู่ใน .tools/report-python ภายในโปรเจ็กต์ ฟอนต์ใช้ TH Sarabun New ที่ติดตั้งในเครื่อง

1. scripts/build-project-report.py สร้าง Word และภาพต้นฉบับ (ต้องไม่เปิดไฟล์ Word เป้าหมายอยู่)
2. อัปเดตสารบัญใน Word แล้วบันทึก
3. scripts/report-html.py สร้าง HTML สำหรับพิมพ์
4. scripts/print-project-report.ps1 ส่งออก AI-Robot-Butler-Report-browser.pdf ด้วย Chrome headless
5. scripts/check-project-report.py ตรวจไฟล์และสร้าง toc-pages.json
6. ทำขั้นตอน 3–5 อีกครั้งเพื่อใส่เลขหน้าสารบัญ หากจำนวนหน้าเปลี่ยนให้ทำซ้ำจนคงที่ แล้วคัดลอก browser.pdf เป็นชื่อ PDF ที่ส่งมอบ

scripts/export-project-report.ps1 เป็นทางเลือกสำหรับ Word automation หากเครื่องปลายทางรองรับ แต่เส้นทางส่งออก .doc/PDF ค้างในเครื่องที่จัดทำรอบนี้ จึงไม่ได้ใช้เป็นไฟล์ PDF ส่งมอบ
