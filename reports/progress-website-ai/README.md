# ความคืบหน้า Website / AI — ฉบับแก้ไข v2

ฉบับ 13 ตุลาคม 2569 มี 19 สไลด์ ใช้ชื่อ Robot Interface สำหรับเว็บไซต์ผู้ใช้หุ่น และตัดหัวข้อการจำลองออกตามคำขอ เปลี่ยนชื่อในสไลด์ ไม่ได้เปลี่ยนโฟลเดอร์หรือ endpoint ของแอป

| หน้า | เนื้อหา |
|---|---|
| 1–2 | ปกและภาพรวมความคืบหน้าทั้งสองฝั่ง |
| 3–8 | Website: หน้าจอ สถาปัตยกรรม แผนที่ POI งานค้าง และผลตรวจ |
| 4 | หน้าที่ Admin Website / Robot Interface และช่องรูป 2 ช่อง |
| 5 | เส้นทาง request → validation → database / robot → live update |
| 7 | งานค้าง: upload แผนที่, แก้แผนที่/กำแพงเสมือน, โหมดหุ่น |
| 9–18 | AI: เทคนิค ขั้นตอน โค้ด ตัวอย่าง ผล benchmark และงานค้าง |
| 12–15 | โค้ด Rules, Zod, request โมเดล และ validation ก่อน dispatch |
| 19 | สรุปแยก Website/AI และตอบคำถาม |

หน้า 4 ใช้ช่องรูปที่เป็น shape แก้ไขได้ ให้ลบข้อความและแทรกภาพหน้าจอของผู้จัดทำ โค้ดเป็น excerpt เพื่ออ่าน ไม่ใช่ฟังก์ชันที่รันเดี่ยวได้ หน้าเรียกโมเดลใช้ systemMessage/userMessage เป็นชื่อย่อแทน objects จริง

ระบบเดิมมี import JSON ไป draft และเก็บ keepout polygons แต่ยังไม่ถือว่าเส้นทาง upload/แก้ SLAM map หรือกำแพงเสมือนบนหุ่นเสร็จแล้ว จึงจัดงานเหล่านี้และโหมดหุ่นเป็นงานค้างตามที่ผู้จัดทำระบุ

ใช้หลักฐานเดิม ไม่ได้ทดสอบหุ่น โมเดล หรือรัน tests ใหม่ ผล 52 tests เป็นผลของระบบรวม ไม่ใช่จำนวนทดสอบฝั่ง Website เพียงอย่างเดียว Benchmark 40/40 เป็น regression บน PC ไม่ใช่ผลการเดินจริงหรือ Jetson

แต่ละช่วงเริ่มจากงานที่ทำแล้วและจบด้วยงานค้าง ไม่มีการอ้างเปอร์เซ็นต์ทั้งโครงการที่ไม่ได้กำหนดเกณฑ์ เติมผู้จัดทำ/อาจารย์ก่อนใช้ ฟอนต์เนื้อหา TH Sarabun New และโค้ด Consolas; ใช้ PDF หากเครื่องพรีเซนต์ไม่มีฟอนต์ ตรวจการตัดบรรทัดใน PowerPoint บนเครื่องที่จะนำเสนอ
